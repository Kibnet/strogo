Результаты нового запуска: [v0](../artifacts/publication/v0-conformance.json) и [E04](../artifacts/publication/e04-conformance.json). Из этих публикационных копий JSON удалены личные пути; runtime receipts внутри отчёта показывают исторический результат этого запуска и не являются переносимыми допусками.

Z3 и Dafny взяты из уже установленного закреплённого toolchain исходного проекта; новая загрузка их архивов в этом прогоне не выполнялась. Первый E04 запуск в сетевой песочнице прошёл формальную проверку, но получил `RestoreFailed` / `NU1301`: доступ дочернего процесса к NuGet был запрещён. После повторного запуска с сетевым доступом полный suite прошёл без изменения кода. Полный успешный E04 прогон занял 177 753 мс; это время проверки, а не benchmark языка или агента.

GitHub Actions в этой публикации не настроен. Локальные результаты не являются свидетельством CI, всех платформ, полного AOT или достижения G05/G06.
